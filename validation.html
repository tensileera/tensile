Evidence is part
of the architecture.

A clear distinction between an analytical model, a component result and an integrated aircraft demonstration. Each claim needs a defined scope.

THE PROGRAM STANDARD

Configuration.
Conditions.
Method.
Result.

HOW TO READ THE PROGRAM

A label for every evidence state.

These categories describe evidence maturity. They are not a claim that every stage has been completed.

01 / ANALYTICAL

A defined model.

Equations, assumptions, system boundaries and sensitivity establish what the calculation actually describes.

02 / COMPONENT

A measured subsystem.

A specific article, method and set of conditions establish the limits of a component-level result.

03 / INTEGRATED

A system demonstration.

Ground and flight tests establish behavior for the configuration and operating envelope actually evaluated.

FEDERAL OPERATING AUTHORIZATION

A defined aircraft.
A bounded scope.

The VSG-HL-01 authorization is separate from performance validation and from larger roadmap platforms. Operations remain subject to the controlling decision and its conditions.
